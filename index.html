LiDAR-based SLAM

GitHub Repository

Keywords: C++, Eigen, Sophus, ICP, Non-Linear Least Squares, Factor Graph

This projects implements a LiDAR-based SLAM system in modern C++, featuring odometry using point-to-point ICP for scan registration. Each incoming LiDAR scan is aligned to a local map represented through a spatial hash table. The next development stages include adding loop closure detection, pose-graph optimization, and extending the system to support multi-sensor fusion (GNSS, IMU, and cameras) using a factor-graph framework. Visualization is handled through ReRun.

Large-Scale LiDAR-Visual Mapping using Gaussian Splatting and Neural Distance Field

Faris Hajdarpasic, Yue Pan, Xingguang Zhong, Cyrill Stachniss
PDF and Presentation
GitHub Repository

Keywords: Python, PyTorch, AutoGrad, Signed Distane Field, Radiance Field, Deep Learning, Clustering

Maps of the environment are essential for autonomous car navigation. Metric maps should be ideally both - geometrically accurate and photorealistic. To achieve this we propose a method that combines LiDAR and camera data and utilizes the radiance field and signed distance field. Furthermore, we address the challenge of dynamic object removal in both sensor modalities. Potentially dynamic objects are detected in the image space using Grounded SAM 2, while Principal Component Analysis (PCA) is employed in the LiDAR space to identify and remove them. As a result, we achieve a geometrically accurate and photorealistic reconstruction of the static world, even in the presence of dynamic elements.
